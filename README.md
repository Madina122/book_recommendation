# Книжный рекомендатель (Book Recommender)

Консольное приложение для поиска и рекомендаций книг через Google Books API.

## Описание проекта

Приложение позволяет находить книги по жанрам, сортировать их по популярности и получать информацию о каждой книге. Используется Google Books API для получения актуальных данных.

## Функциональность

*   🔍 **Поиск книг по жанру** (фантастика, детектив, роман и т.д.)
*   📊 **Сортировка по популярности** (по количеству оценок)
*   ⭐ **Отображение рейтинга** и количества отзывов
*   📚 **Топ-5 рекомендаций** в выбранном жанре
*   🖼️ **Просмотр обложек книг** (ссылки на изображения)
*   📝 **Краткие описания** книг

## Технологии

*   **Язык:** Go 1.21+
*   **API:** Google Books API v1
*   **Формат данных:** JSON
